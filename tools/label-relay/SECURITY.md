# Security

This toolkit is experimental and has not received an independent security audit.
Don't use it with real customers or financial effects without reviewing adapters
and performing acceptance tests.

Never publish real shipping labels, customer addresses, emails, phone numbers,
credentials, storage URLs or provider logs in issues or pull requests.

If you find a vulnerability, use GitHub's private vulnerability reporting for this
repository if enabled. Otherwise open an issue asking for a private reporting
channel **without including exploit details or sensitive data**.

No automatic secret rotation, permanent deletion or public storage is implemented.
